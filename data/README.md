# Data directories

`DATA_PATH` defaults to this directory. The `raw_data` directory contains private source records and converted VWH files, while `processed_data` contains the derived firm clusters and worker panels. Of these data files, only `processed_data/driver_panel_grid.csv` is approved for public distribution. Its codebook is provided in `processed_data/README.md`.

The public archive includes the plotting grid and these directory READMEs. VWH records and individual driver records are not distributed. See the [main README](../README.md) for data access instructions and citations.
